# Notebooks

This folder contains the original project notebooks recovered from the GitHub branches.

## Files

- `01_data_exploration.ipynb`  
  Exploratory analysis of the synthetic ADC conjugation-platform dataset.

- `02_model_selection.ipynb`  
  Original model-training notebook comparing Logistic Regression, Random Forest, and Gradient Boosting on the synthetic benchmark.

- `03_platform_recommender.ipynb`  
  Demonstration interface notebook using Gradio and a serialized model.

## Interpretation

These notebooks are retained for reproducibility and project provenance. They operate on a synthetic benchmark dataset and should not be interpreted as a validated ADC platform-selection workflow.

The revised manuscript-support analyses are implemented as scripts in `../src/`, with outputs under `../reports/`.
