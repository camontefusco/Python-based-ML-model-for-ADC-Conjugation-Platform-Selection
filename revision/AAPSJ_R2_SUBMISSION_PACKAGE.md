# AAPSJ second-round revision package

The final AAPSJ second-round submission package is archived in Google Drive:

https://drive.google.com/drive/folders/1PwETQLWLiPewn6SymfreASws2oN7lrhC

Package file:
- AAPSJ_R2_submission_package.zip

The package contains the point-by-point response letter, revised manuscript, abstract, revised tables, corrected graphical abstract, workflow schematic, individual figures, and submission manifest.

The ZIP is stored in Drive because the complete package exceeds GitHub's standard 100 MB file limit. The repository remains the location for the reproducible Python workflow and source materials; the Drive folder is the archival location for the journal submission artifacts.
